# 🤖 code-companion

**code-companion** est un bot Discord éducatif en Python conçu pour partager automatiquement des ressources utiles en programmation, tech et informatique.

## 🚀 Fonctionnalités

- 🔁 Commande `/ressource` pour afficher un lien aléatoire
- 📚 Liste de ressources personnalisable
- 🔒 Facile à étendre : ajout futur de commandes, système de tags, etc.

## 🧰 Stack technique

- `Python`
- `py-cord` (librairie Discord)
- `dotenv` pour sécuriser les variables d’environnement

## 📦 Installation

```bash
git clone https://github.com/delannoykurt/code-companion.git
